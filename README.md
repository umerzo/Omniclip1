# 🎬 OmniClip — AI YouTube Content Studio

OmniClip is an end-to-end AI YouTube video production studio:
- **Content DNA Analysis**: Ingest any YouTube video or topic and extract hook mechanics, retention strategy, and story arc.
- **Multi-Scene Storyboard Planner**: Generates cohesive scene prompts, camera motion, and character consistency.
- **Voiceover Synthesis**: Edge-TTS natural neural voices across dozens of languages.
- **Agnes Video Generation**: Multi-key automatic rotation across Agnes v2.0 video generation slots.
- **Word-by-Word Kinetic Pop-in Subtitles**: Dynamic bouncing word animations optimized for mobile safe zones.
- **Automated YouTube Publishing Kit**: 3 high-CTR titles, accurate timestamped chapters (`00:00`), and SEO descriptions.

## 🚀 Cloud Deployment
- **Streamlit Community Cloud**: Ready to deploy with zero configuration (`packages.txt` + `requirements.txt` included).
- **Docker**: Production `Dockerfile` included with Linux `ffmpeg` and system fonts.
